# Smart Habit Tracker

Веб-приложение для отслеживания и управления персональными привычками с визуализацией прогресса.

## ✨ Особенности

- **Авторизация пользователей** - регистрация и вход через email/пароль или Google аккаунт
- **Трекер привычек** - создание, редактирование, удаление и отслеживание ежедневных привычек
- **Визуализация прогресса** - календарь выполнения и графики прогресса
- **Cloud-синхронизация** - данные хранятся в Firebase и доступны с любого устройства
- **Адаптивный дизайн** - корректное отображение на мобильных и десктопных устройствах

## 🛠 Технологии

- **Frontend:** React, TypeScript, Redux Toolkit, React Router
- **Backend:** Firebase (Authentication, Firestore)
- **Стилизация:** CSS Modules
- **Сборка:** Vite
- **Хостинг:** GitHub Pages

## 🚀 Быстрый старт

1. **Клонируйте репозиторий**:

```bash
git clone https://github.com/Sw1ftFox/course-work.git
```

2. **Войдите в папку проекта**:

```
cd .\course-work\
```

3. **Установите зависимости**:

```bash
npm install
```

4. **Настройте окружение**:

- Создайте файл .env.local в корне проекта на основе .env.example
- Добавьте ваши Firebase keys

```bash
# .env.example
VITE_FIREBASE_API_KEY=ваш_apiKey
VITE_FIREBASE_AUTH_DOMAIN=ваш_authDomain
VITE_FIREBASE_PROJECT_ID=ваш_projectId
VITE_FIREBASE_STORAGE_BUCKET=ваш_storageBucket
VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_messagingSenderId
VITE_FIREBASE_APP_ID=ваш_appId
```

5. **Запустите приложение**:

```bash
npm start
```

6. **Откройте в браузере**:

```bash
http://localhost:5173
```

## 🧩 Основные функции

### Управление привычками

- Создание привычек с установкой целей (дней в неделю)
- Отметка выполнения привычек на календаре
- Просмотр статистики и прогресса по каждой привычке (клик на название привычки)
- Визуализация прогресса через графики и календари
- Редактирование описания привычки (отредактируйте поле и нажмите "Сохранить изменения")
- Удаление неактуальных привычек

### Авторизация и безопасность

- Регистрация и вход через email/пароль
- Авторизация через Google аккаунт
- Защищенные маршруты с проверкой аутентификации
- Разделение данных между пользователями
- Хранение данных пользователя между перезагрузками страницы (localStorage)

### Аналитика и отчетность

- Прогресс-бары выполнения целей
- Календарь с историей отметок
- Система трёх-этапного стрика:
  - 3 дня подряд - "👍 Хорошее начало!"
  - 7 дней подряд - "🎉 Отлично! Так держать!"
  - 30 дней подряд - "🔥 Невероятная дисциплина! 30 дней подряд!"
